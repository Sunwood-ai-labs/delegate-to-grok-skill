# v0.1.0 — 安全な Grok Build 委譲

Windows 向け Codex スキルパッケージの初回公開リリースです。

## 主な内容

- すべてのヘッドレス実行を、直接のプロンプトコマンドライン引数ではなく PowerShell ラッパーへ固定します。
- 一時プロンプトファイルにより、複雑な入力、多言語入力、引用符を保持します。
- 可変な Grok 認証状態を隔離し、実行前検査・タスク完了・実行後検査がすべて成功した場合だけ反映します。
- 名前付きミューテックスで呼び出しを直列化し、Grok と OAuth セッションの重複を防ぎます。
- 指定ディレクトリの境界、Grok 内サブエージェント無効、クロスセッションメモリ無効、読み取り専用を既定にします。

## 検証

リポジトリには Windows 向けの決定的な検証スクリプトと GitHub Actions ワークフローがあります。ラッパー構文、スキルメタデータ、ヘルプ出力を確認し、Grok CLI が呼ばれる前に許可外ディレクトリが拒否されることを検証します。

## 対象範囲

このリリースは `v0.1.0` に含まれる全履歴を対象とします。自動検証に Grok アカウントは不要です。対話的な利用時の認証動作はガイドで説明しています。
